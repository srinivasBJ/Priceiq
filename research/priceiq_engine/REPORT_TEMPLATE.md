# PriceIQ Research v1.0 report template

## Historical facts

The original deterministic PriceIQ implementation and catalog are lost. This work does not recover or claim to be that implementation.

## Newly defined methodology

State the fixed features, version, and decision precedence from `CALIBRATION_PROTOCOL.md`.

## Calibration results

Report the predeclared calibration cutoff, dataset hash, eligible calibration cases, candidate count, selected thresholds, objective, score, and frozen configuration hash.

## Unseen test results

Report only decision points strictly after the frozen cutoff, including metrics and limitations. Do not treat ex-post outcomes as forecasts or realised savings.

## Publication status

State whether a genuine longitudinal dataset was used. Snapshot, transaction, sparse smoke-test, or synthetic test data cannot support publication claims.
